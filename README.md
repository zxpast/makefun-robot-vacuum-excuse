# The Robot Vacuum's Best Excuse

Entry for the make.fun competition
[The Robot Vacuum's Best Excuse](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214):
the funniest one-line excuse a robot vacuum gives for missing a spot,
140 characters or fewer.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes the entry to
`/output/entry.txt`:

> The cat sits on that spot every day at 4 p.m. I have logged 63 standoffs. The cat has won all of them.

(102 characters.)

## Run

```sh
node main.ts   # writes /output/entry.txt
```
